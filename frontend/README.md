# 교육용 숏폼 프론트엔드

React와 Vite로 구현한 홈·탐색·회원 메뉴, 학습 및 로그인 화면입니다.

## 실행

```powershell
npm ci
npm run dev
```

터미널의 Local 주소를 브라우저에서 엽니다.

## 화면 경로

| 경로 | 화면 |
| --- | --- |
| `/` | `/home`으로 이동 |
| `/home` | 홈 영상 목록과 카테고리 필터 |
| `/explore` | 탐색 영상 목록 |
| `/login` | 로그인 화면 |
| `/signup` | 회원가입 화면 |
| `/forgot-password` | 비밀번호 찾기 화면 |
| `/myChannel` | 내 영상 목록 |
| `/videos/:videoId` | 등록된 영상 재생 |
| `/myPage` | 마이페이지 화면 자리 |
| `/channel/upload` | 영상 등록 (파일 미리보기·영상 정보·확인 퀴즈) |
| `/learn/1` | 첫 영상 학습 |
| `/learn/:videoId` | 영상·퀴즈·채점 결과·추천 |
| `/learn/summary` | 이번 탭의 학습 요약 |

홈의 사이드바에서 학습 화면으로 이동할 수 있습니다. 학습 화면은 세로형 플레이어의 전체 화면 구성을 유지하며 홈으로 돌아갈 수 있습니다.

## 백엔드 연결 상태

- 회원가입·세션 로그인·로그아웃과 헤더의 로그인 회원 정보는 실제 API에 연결했습니다. 로그인하면 홈으로 이동합니다.
- 내 채널에서 DB의 카테고리·개념 태그를 선택하고 MP4 영상을 업로드할 수 있습니다. 영상 파일과 영상 정보 JSON을 함께 전송합니다.
- 원하는 카테고리나 개념 태그가 없으면 업로드 화면에서 직접 추가합니다. 영상 길이는 파일 선택 시 자동으로 읽습니다.
- 영상 선택 시 약 0.5초 지점을 JPEG 썸네일로 만들고 미리보기를 표시합니다. 영상과 함께 저장해 홈·탐색·내 영상 목록에서 사용합니다.
- 홈·탐색은 DB의 공개 영상을 최신 등록순으로 표시합니다. 12개씩 불러오며 홈에서 실제 카테고리로 필터할 수 있습니다.
- 홈·탐색·내 영상 목록에서 카드를 누르면 해당 파일을 재생합니다. 내 채널에는 로그인한 회원의 영상만 표시하며 업로드 후 목록을 갱신합니다.
- 썸네일이 없거나 이미지를 불러오지 못하면 기본 이미지를 표시합니다. 검색과 비밀번호 찾기 이메일 발송은 연결 전입니다.
- 학습 화면은 기본적으로 목업으로 동작합니다. `.env.example`을 참고해 개인 설정을 작성합니다.
- `VITE_USE_MOCK=false`이면 실제 학습 API를 호출합니다. 채점·추천은 로그인 세션 기준이라 먼저 로그인해야 합니다. 다음 영상 조회는 추가 작업이 필요합니다.
- 개발 서버의 `/api` 요청은 `http://localhost:8080`으로 전달합니다. 인증·업로드·학습 API 모두 세션 쿠키를 사용합니다.
- 영상 등록 화면은 `VITE_USE_MOCK`을 따라 목업으로 동작합니다. API 호출은 `src/features/videoUpload/api/videoUploadApi.js` 한 파일에 모았고, 실제 모드는 PR #7의 `GET /api/video-categories`, `POST /api/videos`(multipart) 계약에 맞췄습니다.
- 학습 요약은 브라우저 `sessionStorage`를 사용하며 서버 로그인 세션 및 DB 시청 기록과 별개입니다.

```powershell
npm run lint
npm run build
npm test
```
